# Comunidade e guardiões

Propostas abertas, aprovação dos guardiões e publicação da main.

## Propósito

Qualquer pessoa pode ler este repositório, colocar perguntas, fazer um fork e propor um pull request. A entrada na main exige a revisão do guardião configurado e verificações aprovadas. Não é necessário acesso de escrita para propor conhecimento. Os exemplos devem ser sintéticos ou devidamente anonimizados.

## Guardiões iniciais

Guardião inicial: @ismael-lab. A identidade está em CODEOWNERS. Com um único guardião e sem bypass, um pull request da autoria desse guardião precisa de outro guardião autorizado para ser aprovado; a autoaprovação não substitui a revisão.

## Fluxo de contribuição

1. Abrir uma issue com o contexto e a melhoria proposta.
2. Editar o Markdown num fork ou num ramo de trabalho permitido.
3. Manter idiomas e diagramas consistentes; explicar diferenças de tradução.
4. Abrir um pull request com justificação, evidências e limitações.
5. O guardião revisa o conteúdo e as verificações; alterações novas invalidam aprovações antigas.
6. Um guardião integra a alteração aceito na main protegida.
7. O site importa uma versão fixada da main e apresenta a revisão de origem em cada guia.

## Publicação do conhecimento

O site lê uma cópia versionada da main aprovada, nunca um ramo de contribuição. Os mantenedores executam a sincronização de conhecimento e a publicação documentadas. Ler, editar e publicar são passos distintos. Uma proposta num pull request não integra automaticamente o framework publicado.

## Escopo e limites

Textos, diagramas e modelos originais do framework: CC BY 4.0. Código do site: MIT. As marcas KDV e os referenciais de terceiros conservam seus próprios direitos; as licenças não concedem direitos sobre marcas.

## Limites de release e revisão

Qualquer pessoa pode propor alterações. As releases oficiais são marcadas a partir de revisões aprovadas na main protegida; o site importa a revisão exata e a identifica com a versão do framework. Site e framework mantêm versões independentes. A referência v1.0.0 continua disponível no histórico de releases.
