# Application data inventory

Operator supplied by the client: Lab of Codes & Kolmeia. Privacy contact: info@kolmeia.io. Units: Braga, Portugal; Florianópolis, Brazil.

| Element | Processing | Persistence / recipient |
| --- | --- | --- |
| Language links | Explicit localized routes | None in application storage |
| Checklist | Checkbox values and count in the open document | Page memory only; discarded on reload |
| Canvas | User-entered product fields assembled into Markdown | Page memory and user-initiated local download; no network submission |
| Template download | Static Markdown, CSV, supplied PT-BR Office files and diagrams | User device |
| Theme | Explicit choice of light/dark | Browser localStorage `kdv:tema` |
| Reader profile | Explicitly selected professional role; remove using the profile chip | Browser localStorage `kdv:perfil`; no network transmission |
| Reading progress | Guide pages visited in this document session | Page memory; discarded on reload |
| Quick search | Local catalogue search | Page memory; no search service |
| Application cookies, analytics, remote fonts | Not used | None |
| Hosting | Hostinger public hosting; OpenAI Sites owner-private preview connection/authentication | Provider policy and configuration; outside app control |
| External links | Navigating to GitHub, KDV or reference publishers | Destination's own processing and policy |

No optional application tracking is enabled. A theme preference and reader profile are saved only by explicit user interaction. Canvas, checklist and reading inputs stay in the browser. The privacy page describes this behaviour in all four languages and explains that display language does not determine the applicable jurisdiction. Hosting providers may process connection/security data under their own policies; private preview sign-in is separate from the public site.

The operator should confirm actual hosting recipients, lawful bases, retention and rights handling before a public/domain release, and revise the notice if introducing analytics, forms, embeds, accounts or new processors. Application measures are not a certification of legal compliance.
