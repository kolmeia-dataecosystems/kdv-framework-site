# Editorial provenance and reference boundaries

Reviewed 18 October 2026. This repository contains original public explanations, not a copy of the source project or its internal operational records.

## Client-provided context

The client described an open, bee-inspired operational framework, powered by KDV Ecosystems and directed to the data community. The supplied KDV brand identity informs the monochrome typographic, grid and pixel system. No proprietary Delight font file was supplied or redistributed.

## Reference project

The local `kolmeia-dataecosystems/kdvcloud-eu` checkout was read at commit `07941fee75c6d5ea498960b2d84745ed05ba874a`. Relevant conceptual documents were `docs/arquitetura/framework-governanca-kdv.md`, `docs/arquitetura/modelo-de-dados-integrado.md` and `docs/arquitetura/visao-geral.md`.

The governance document is explicitly a draft dated 11 October 2026. It distinguishes implemented, proposed and pending product behavior. The website therefore extracts conceptual responsibilities and evidence, without claiming that draft technical features are generally available. The source documents, operational history, network topology, credentials, infrastructure configuration and private project materials are not redistributed.

The existing institutional KDV website supplied brand context and the distinction between the open method, Kolmeia foundation, products and commercial services. `kdvframework.org` was supplied by the client as the independent framework domain; its content was not retrievable by the research tool during this run. No claim is made that the new text transcribes or replaces the currently hosted domain, and no DNS change was made.
