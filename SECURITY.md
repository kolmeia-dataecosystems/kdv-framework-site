# Reporting a security or privacy issue

Contact info@kolmeia.io privately. Include the affected URL or file, impact and a minimal reproduction using synthetic data. Do not publish credentials, private client information or a working exploit in a public issue. Do not test infrastructure or other users' accounts without authorisation.

This static site does not collect canvas/checklist data or use application cookies. Its hosting provider has separate authentication and connection processing. There is no promised security-response SLA for this initial community edition.
